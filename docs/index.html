The Pulse

Concurrent ICMP probes across your entire infrastructure. Per-host quality scores (0–100) with P99 latency, score degradation alerts, and six scoring dimensions — displayed directly on each host card.

Flow. Measured.

A responsive Quality Assessment dashboard with 1 min / 5 min / 1 hour windows. Cards, metrics, and host-health tables adapt cleanly from wide two-column views to compact layouts.

The Path Forward

Visual traceroute and continuous MTR. A geographic hop-by-hop journey from your local IP to the global edge — no repeated password prompts, ever.

Always Present

Small, medium, and large WidgetKit extensions with live host data. Menu bar shows average, worst, fastest, or a specific host — in a monospaced, jitter-free layout.

Quick Actions

Web, SSH, and custom service shortcuts grouped by host. Read-only tailnet inventory over an OAuth client, an opt-in admin mode for device authorization and route approval, and Bark remote push one click away.
