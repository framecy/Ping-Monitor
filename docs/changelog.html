Version History

Every improvement, every fix — documented with precision.

v2.5.0 Latest 2026-08-22
▼
Changed
  • Tailscale 集成成为真正的开关：设置项此前只隐藏界面入口，应用启动仍会探测 CLI、导入过的节点仍用 tailscale 探测、OAuth 凭据存在时仍轮询 API。现在关闭即全面静默：零 CLI 检测、零 API 请求、探测全部退回普通 ping，未安装 Tailscale 的机器不再有任何派生进程与报错。默认关闭，此前已开启的用户保持开启。
  • 开关切换即时生效：监控运行中切换集成，标准 ICMP 探测自动重启并相应升级/退回，无需重启应用。
Added
  • 集成状态提示：设置页开关下方实时显示 CLI 检测结果（含路径）或控制面凭据状态；安装 Tailscale 后重开设置页即自动识别。
v2.4.1 2026-07-31
▼
Fixed
  • 网速「全部接口」速率叠加：系统中并存的十余个隧道设备会对同一份流量重复计数，导致总速率数倍于实际。现只统计承载默认路由的物理接口，隧道流量单独呈现。
  • 主机详情页卡片挤在左侧：并排卡片的自适应栅格会排出远多于实际需要的列数，卡片被压在页面左侧并留下大片空白。
  • 详情页文本溢出：质量分行不再被截断，延迟统计数值不再折行。
Updated
  • 响应式栅格收敛：统计页与详情页共用同一套宽度断点与等高单元格实现。
v2.4.0 2026-07-31
▼
Added
  • Tailnet 全局监管：通过 Tailscale OAuth client 只读同步整个 tailnet 的设备清单、在线状态、标签、密钥有效期与可用更新，不依赖本机能否连通对端。PingMonitor 不注册为 tailnet 节点、不承载 tailnet 流量。
  • 管理模式：默认关闭；开启后可进行设备授权、子网与 exit-node 路由审批、密钥过期开关、标签编辑与设备删除，破坏性操作强制二次确认。
  • 凭据安全：OAuth client id/secret 存入系统钥匙串，不写入明文配置文件，界面永不回显 secret；设置页内置六步获取引导。
  • 接口分组：网络接口按族合并展示、可展开，承载默认路由的分组带「默认出口」标识。
Fixed
  • 网速统计虚高：总速率此前对全部 12 个物理类接口求和，其中包含 Apple 网络协处理器管理口与雷雳/USB/桥接成员。现只统计默认路由的真实出口。
  • 探测进程泄漏：Tailscale 探测循环在应用被强制退出后会被系统接管并按旧参数持续运行，与新实例叠加。现随宿主进程一同退出。
  • Ping 间隔不生效：间隔在探测进程启动时写入，修改设置后会自动重新应用到所有未配置自定义命令的主机。
  • 侧边栏与表格布局：侧边栏不再被内容区挤压，分隔条不再出现色块缝隙；主机健康矩阵列宽改为按内容自适应，消除宽窗口下的大片留白。
Updated
  • 设计令牌统一：语义状态色取代 20 处重复实现，107 处圆角字面量与 118 行硬编码颜色迁移至令牌，修复浅色模式下不可见的描边。
  • 字体系统：中文使用 PingFang SC、英文使用 SF Pro Text，18 种字号收敛为 10 档常规尺度。
  • 表格斑马纹：主机健康矩阵与接口列表改用半透明色块区分行，替代分隔线。

v2.2.2 2026-07-13
▼
Fixed
  • macOS 26 (Tahoe) 启动崩溃：startTCPProbe 的 DispatchSource 定时器回调捕获 @MainActor 隔离的 self 并在后台队列执行，Swift 6 执行器隔离前导代码在更严格的 Tahoe 运行时触发 _dispatch_assert_queue_fail → SIGTRAP，首个 TCP 探针 tick 一触发即崩溃。改为在主队列驱动定时器、以纯回调式 measureTCPConnectLatency 取代 async 版本（TCP I/O 仍在 NWConnection 私有队列，仅结果回调写回 pendingUpdatesBuffer，与 ICMP 的 parsePingLine 同构 off-actor 模式）。
  • 关闭窗口后无法从菜单栏重开：新增 windowShouldClose 拦截红按钮关闭，改为 orderOut + .accessory 并返回 false，窗口仅隐藏、与 toggle 对称；showWindow 改用 NSApp.activate() + orderFrontRegardless() 兜底置前，修复 Tahoe agent app 下窗口无法带回前台的问题。
v2.1.2-R12 2026-04-14
▼
Added
  • 探针诊断框架：ProbeFailureReason / ProbePathKind / HostProbeDiagnostic 精细化分类每次 Ping 失败根因（超时/DNS/路由/防火墙），支持失败路径追溯。
  • 网络质量评分引擎：QualityDimensionScores 多维评分（延迟/抖动/丢包/稳定性），NetworkQualityEvent 实时事件流，支持 1h/6h/24h 历史趋势窗口。
  • PrivilegedManager：基于 FIFO 命名管道的持久化授权会话，彻底消除 Traceroute/MTR 每次弹出的授权窗口。
  • KeepAliveManager：三档探测策略（Passive/Intensive/Adaptive），SSH 主机自动升频，空闲主机自动降频省电。
  • ConfigManager：统一配置存储入口，支持跨模块共享。
  • FolderMonitor：DispatchSource 文件系统监听，实时感知配置目录变更。
  • QualityEngineTests：网络质量引擎单元测试套件。
Updated
  • TracerouteManager：集成 NSLookup、TraceRouteContext 智能路由上下文、接口优先级排序（物理网卡 > VPN > 其他）。
  • TailscaleManager：Exit Node 一键切换与批量延迟测试、路径诊断、自定义命令执行。
  • HostDetailView / EditableHostCard：主机详情页与卡片深度功能扩展。
  • NetworkSpeedManager：网速采集逻辑重构，稳定性与精度提升。
  • build.sh + scripts/bump_build.sh：自动化版本号递增流水线，支持 --feature / --bug 参数。
Fixed
  • 移除临时测试文件（test.swift / parse_test.swift / build_output.txt）。
  • 构建号修正（Codex 重置导致的 Build 4 → 112）。
